# SovereignInterpreter v1.0.0 — Sovereign Edition

SovereignInterpreter **v1.0.0** is the first stable **Sovereign Edition** release: a local-first, offline-capable chat→code→console interpreter with doctrine enforced in code — not only in docs.

## Doctrine notes

- **Not affiliated with upstream**; independent fork with cloud SDKs removed
- **Policy sandbox, not OS Seatbelt** — `safe` / `strict` / `full` gate Python, shell, and filesystem roots in-process
- **Kill-switch** — presence of `.kill_switch` (configurable) raises `KillSwitchError` and halts protected ops
- **Universal fence rule** — model-fenced code never auto-runs without explicit intent, confirm, or `%run`
- **`allow_cloud: false` by default** — non-local LLM URLs are rejected

## New magics

| Magic | Role |
|-------|------|
| `%help` | Magics, doctrine dials, sandbox modes, model/endpoint, memory |
| `%status` | Live sandbox, auto_run, model, endpoint, roots, kill-switch, memory |
| `%info` | Local-only version / platform / session dump |
| `%undo` | Drop last user turn and everything after |
| `%save` / `%load` | Conversation JSON import/export |
| `%memory export\|import` | Memory pack JSON import/export |
| *(unchanged)* `%reset`, `%auto_run`, `%model`/`%models`, `%run`, `%sandbox` | Session / model / exec / policy |

## REPL UX improvements

- Labels: `[system]` / `[model]` / `[confirm]` / `[run]` / `[console]` / `[skip]` / `[error]`
- Soft ANSI on tag only (`NO_COLOR` respected)
- Dim SI wordmark + boxed Ready banner (model / endpoint / sandbox / auto_run)
- Confirm: `[confirm] {lang}` + dim boxed full-code preview + `Run this code? [y/N]:` (deduped)
- Thinking timer: `[model] thinking…` then `[model] thinking… (Ns)` (cleared `\r` line)
- Multi-line input via `"""` … `"""`
- One-shot: `sovereigninterpreter run "…"`
- Sandbox shell tip: blocked `!` → `[error]` + `[system] Tip: use %sandbox full…`
- Sandbox policy blocks → `[skip]` only (no misleading `[run]`)

## Safety improvements

- Intent detection + universal fence rule (from 0.2.x lineage)
- Sandbox mode matrix + filesystem jail (`effective_roots`)
- Typed envelopes: `PythonError`, `ShellError`, `ModelOutputError`, `SandboxBlocked`, `ExecutionDenied`, `KillSwitchError`, `CloudForbiddenError`, `SafetyViolation`
- Confirm-first defaults (`auto_run: false`); `auto_run` only skips confirm when execution was already requested

## Packaging consistency

- `__version__` = `1.0.0`
- `setup.cfg` version = `1.0.0`
