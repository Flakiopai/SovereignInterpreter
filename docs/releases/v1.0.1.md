# SovereignInterpreter v1.0.1 — Operator subsystems

Patch release on the **1.0** line. Adds sandboxed tools, multi-model loader, memory packs v2, agent overlay, and workflow runner — all on the existing chat→respond→computer pipeline with doctrine enforced in code.

## Highlights

| Area | Summary |
|------|---------|
| Tools | `Computer.call_tool` + workspace jail |
| Models | Local registry; `%model` reloads adapter |
| Memory v2 | `workspace/packs/*.pack.txt`; inject per LLM call |
| Agent | Overlay on `respond()` (`%agent on\|off`) |
| Workflows | `workspace/workflows/*.yaml`; orchestrate only |
| Doctrine | Kill-switch, `allow_cloud`, sandbox, jail unchanged |

## Compatibility

- Public API: `SovereignInterpreter.chat()` unchanged in shape
- Default doctrine dials unchanged (`allow_cloud: false`, `sandbox_mode: strict`, confirm-first)
- No cloud SDK / telemetry dependencies
