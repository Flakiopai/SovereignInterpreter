# SovereignInterpreter v0.3.0 — Sovereign Edition (pre-v1.0 polish)

SovereignInterpreter v0.3.0 is the **Sovereign Edition — pre-v1.0 polish** release: tighter local execution control, labeled REPL chrome, and operator magics — without changing the sovereign doctrine or the universal safety rule.

## What's new

- **Sandbox modes** — `safe` / `strict` (default) / `full` control Python, shell, and filesystem roots via config and `%sandbox`
- **Error-handling envelope** — typed categories (`PythonError`, `ShellError`, `ModelOutputError`, `SandboxBlocked`, `ExecutionDenied`, …) remap in the REPL to `[error]` / `[skip]`
- **REPL UX labels** — `[system]`, `[model]`, `[confirm]`, `[run]`, `[console]`, `[skip]`, `[error]` with soft ANSI on tags (`NO_COLOR` respected)
- **Banner** — dim SI wordmark + boxed Ready (model / endpoint / sandbox / auto_run)
- **Magics** — `%help`, `%status`, `%info`, `%undo`, `%save`/`%load`, `%memory export|import` (plus existing `%reset`, `%auto_run`, `%model`/`%models`, `%run`, `%sandbox`)
- **Confirm polish** — single `[confirm]` + dim boxed full-code preview + truthful `Run this code? [y/N]:` (deduped; no fake `e`)
- **Thinking timer** — `[model] thinking…` then `[model] thinking… (Ns)`
- **One-shot exec** — `sovereigninterpreter run "…"`
- **Multi-line input** — `"""` … `"""` blocks in the REPL
- **Sandbox skip fix** — policy blocks show `[skip]` only (no misleading `[run]`)
- **Runner cores** — `_run_python` / `_run_shell` centralize execution under sandbox policy
- **Config knobs** — `sandbox_mode: strict` and `show_tracebacks: false` in `sovereign.yaml` (`max_turns` removed; bound is `max_iterations`)
- **Filesystem jail alignment** — `safe`/`strict` narrow effective roots to `./workspace`; `full` uses configured `allowed_roots`
- **Shell shortcut gating** — `!command` respects sandbox (blocked unless `full`; tip suggests `%sandbox full`)
- **Tests** — 67 offline tests covering sandbox matrix, error envelope, and display labels
- **Unchanged doctrine** — universal safety rule, intent detection, `%model`/`%models`, `%reset`, auto-detect, and hallucination-loop prevention remain as in v0.2.0

## Upgrade notes

- Default sandbox is **`strict`**: Python allowed, shell/`!` blocked, FS roots narrowed to `./workspace`
- Use `%sandbox full` (or `sandbox_mode: full`) only when you accept shell + broader roots
- Set `show_tracebacks: true` only when debugging; default stays quiet envelopes
